# Sobhanachala Luxury eCommerce

A cinematic, high-end fashion eCommerce platform built with a modern tech stack focusing on visual excellence and immersive user experience.

## ✨ Features

- **Cinematic Experience**: Ultra-smooth animations and transitions powered by GSAP and Framer Motion.
- **Luxury Aesthetic**: Minimalist, premium UI designed for high-fashion storytelling.
- **Smooth Interaction**: Integrated Lenis smooth scrolling and custom magnetic cursor.
- **Responsive Navigation**: Full multi-page routing with an editorial approach.
- **Performance Focused**: Optimized video delivery (HLS.js) and modern build tooling (Vite + Tailwind v4).

## 🚀 Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS v4
- **Animations**: GSAP, Framer Motion
- **Scrolling**: Lenis
- **Icons**: Lucide React
- **Deployment**: Vercel

## 📦 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/konapalask/sobhanachala.git
   ```

2. **Install dependencies**:
   ```bash
   npm install --legacy-peer-deps
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

## 🛠 Project Structure

- `src/components`: UI components and layout providers.
- `src/sections`: Major homepage sections (Hero, Lookbook, etc.).
- `src/pages`: Individual page components (About, Contact, Collections).
- `src/lib`: Utility functions and GSAP/animation configurations.
